# BAFTA film awards 2021–2025

Five ceremony years using the same twelve categories as 2026: Best Film, Director, Outstanding British Film, four acting categories, Original and Adapted Screenplay, Film Not in the English Language, Documentary and Animated Film. Film cards repeat across categories, with the winning film first and nominated people retained.

The official source contains 60 categories, 344 nominations and 175 distinct films. Annual film counts: 38 (2021), 37 (2022), 36 (2023), 30 (2024), 34 (2025). Animated Film retains its actual three/four nominees; Outstanding British Film retains all ten. No short films, craft categories, honorary awards or longlists are included.

Sources:

- https://www.bafta.org/awards/film/?award-year=2025

The normalized official records are in `imports/bafta-2021-2025-source.json`. The final provider identity audit is `imports/bafta-2021-2025-audit.json`. Matches require a normalized title or reviewed alias, a ceremony release window, feature runtime, unique identity and all nominated actor/director credits. Reviewed director checks distinguish The Dig, Limbo, Les Misérables, The Rescue, Bird and I'm Still Here. Everybody's Talking About Jamie uses the English-language feature, rather than the Japanese stage production with the same title and credited director. Borat Subsequent Moviefilm uses its full provider subtitle and reuses the existing catalogue ID.

Existing IDs, film metadata, ratings, notes and history are preserved. New films are appended and receive provider metadata. No database changes are executed by this PR.

After merging, `imports/bafta-2021-2025-catalogue-sync.sql` registers only the new public catalogue rows and provider links. It is insert-only, can be rerun, and aborts conflicting identity mappings. SQL preservation and conflict handling are verified using an isolated Postgres engine.

Final audit: 175 verified identities, 117 reused records, 58 additions, zero unresolved. Every addition has a poster. All 29 local tests pass; canonical validation finds 2,518 films and zero errors. Existing catalogue and detail metadata match the merged baseline exactly.
