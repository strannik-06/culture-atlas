# Golden Globes film awards 2011–2015

Five ceremony editions cover the established twelve film categories. The normalized official-source file is `imports/globes-2011-2015-source.json`; `scripts/collect-globes-2011-2015.py` regenerates it using the Golden Globes' public awards database. Original category names, nomination IDs and individual film source links are preserved. HTML entities are decoded and trailing indexing articles are moved to the start of film titles.

The six Drama nominees in 2012 and the three Animated nominees in 2014 are intentional. No modern five/six-nominee rule is imposed on historical editions. Multiple actors nominated for the same film remain separate nomination records. TV, score/song, honorary awards and other film categories remain outside this scope.

## Official evidence

Data: `https://goldenglobes.com/wp-json/awdb/v1/winners-and-nominees/?year=YEAR`, for each year 2011–2015. Public pages: `https://goldenglobes.com/winners-nominees/?year=YEAR`.

Contemporary checks include the full [69th nominations announcement](https://goldenglobes.com/articles/69th-annual-golden-globe-awards-nominations/), the [71st nominee reactions](https://goldenglobes.com/articles/71st-annual-golden-globe-awards-nominee-reactions/), the [2011 results report](https://goldenglobes.com/articles/glee-and-social-networking-golden-globes/), and the [2015 results report](https://goldenglobes.com/articles/another-golden-night/). Some legacy announcement articles link to nomination pages that no longer exist; the current official awards database supplies the complete records.

The API omits Steven Zaillian from the 2012 *Moneyball* screenplay nomination. The contemporary official press release explicitly names Stan Chervin, Steven Zaillian and Aaron Sorkin. The normalized row restores this missing writer, retains `source_original_person`, and links the official announcement in `person_source`. A root `source_corrections` record documents the exact nomination ID (72166), original value and correction. No nomination is removed or added.

Ceremony dates are January 16, 2011; January 15, 2012; January 13, 2013; January 12, 2014; and January 11, 2015. Each event includes `ceremony_date` and the corresponding official timetable or announcement URL in `date_source`.

Source validation requires the correct historical category sizes, one winner per category, unique nomination IDs and film-only source links. There are zero extra-year source rows or unresolved source nomination records in this batch.
